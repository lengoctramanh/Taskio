# Taskio

Taskio la du an quan ly cong viec, duoc xay dung theo huong MVP voi frontend va backend tach rieng.

## Muc tieu

- Xay dung API MVP cho ung dung Taskio.
- Setup khung du an ban dau de phat trien frontend va backend.
- Quan ly source code bang Git/GitHub.
- Chuan bi moi truong de test API bang Postman sau nay.

## Cong cu su dung

- Visual Studio Code
- NodeJS
- npm
- Git/GitHub
- Postman

## Cau truc thu muc

```txt
taskio/
  frontend/
  backend/
  docs/
    Taskio_API_MVP.md
  docker-compose.yml
  README.md
```

## Tai lieu API

- Xem tai lieu API MVP tai: `docs/Taskio_API_MVP.md`

## Cach nop bai voi Git

```bash
git status

git commit -m "Setup Taskio project structure and API MVP docs"
git branch -M main
git remote add origin <link-repository-github>
git push -u origin main
```
